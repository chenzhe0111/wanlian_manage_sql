# 线上目标问答 · 分析思路（已固化）

来源：`QA_ANALYSIS_PLAYBOOK_DRAFT.md` 全量收编。实现：`qa_analyze.py`；Cursor skill：`.cursor/skills/wanlian-online-data-analysis/SKILL.md`。

**默认对比基准**：vs 时间进度（表内判定：达成 ≥ 时间进度−5pp → 正常，否则风险）。用户若说「和上周比」则切周环比。

**输出原则**：先总判 1～2 句 → 点名谁拖/谁托 → 必要时下钻类型或新老；忌全表速览堆砌。

## A0. 基础查数（直答，不归因）

| 项 | 内容 |
|---|---|
| 问法 | 整体运单量；整体运单量截止到现在是多少；线上/电销/投流/裂变/调度运单量；投流新货主数 |
| 看数 | 整合表当月截至 O1、上月整月同指标列；周度 CSV 最近一周（周三起，含进行中） |
| 怎么判 | 凡问指标值（运单、GTV、客单价、占比、货主、成交率等）都直答三段：当月截至、当周截至、对比上月。可累计量用日均=累计÷天数；率/客单/占比/峰值按水平比、不除天数。周度没有的指标写明暂无。带「为什么」的仍走归因 |
| 代码 | `answer_lookup` |

### G1. 投流 / 电销留存·新增漏斗（必出）

整合表第七部分字段（上月整月实际列 vs 本月截至 O1 列）：

**留存：** 运单量、发货货主数、成交货主数、货主成交率、单货主成交运单数  
**新增：** 同上五类  

行号：电销留存 113–117 / 新增 120–124；投流留存 142–146 / 新增 149–153。  

输出时：运单与货主数给「累计 + 日均」；成交率与单货主运单给人效/转化水平对比；并点一句卡点（成交率 / 人效 / 发货→成交漏损）。
